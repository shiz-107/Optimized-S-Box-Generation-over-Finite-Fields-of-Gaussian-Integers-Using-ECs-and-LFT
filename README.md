# Optimized-S-Box-Generation-over-Finite-Fields-of-Gaussian-Integers-Using-ECs-and-LFT
This repository focuses on generating efficient S-boxes using elliptic curves (ECs) and linear fractional transformations (LFT) over finite fields of Gaussian integers, incorporating optimization techniques to enhance cryptographic properties.
Key Features:
Utilizes elliptic curves (ECs) and linear fractional transformations (LFT) for S-box construction.

Applies optimization techniques to identify the most suitable S-boxes.

Aims for high non-linearity (NL) and low linear approximation probability (LAP).

Ensures strong differential uniformity for enhanced security.

Implements mathematical structures in Python to improve cryptographic strength.
